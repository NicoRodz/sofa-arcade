# Manchazo audio suite (tribal house)

Audio for Manchazo (4v4 team paint party game on a TV). Everything here is generated by code and can be regenerated.

- **Tempo:** 120 BPM in every music file (1 bar = 2.000 s).
- **Key:** A minor. Round progression Am - Am - F - G (4-bar phrase, repeated). Lobby: Am7 - Fmaj7 - C - G(add). Win resolves to A major, lose falls through the A minor triad.
- **Format:** Ogg Vorbis, 44.1 kHz stereo, libvorbis q6.

## How to use the round layers

The three round layers share BPM (120), key (A minor), chord map, kick grid and exact length (1,411,200 samples). Start all three in sync and crossfade their volumes, for example base -> 30s -> final10. Their loudness rises slightly on purpose (-15.6, -15.0, -14.3 LUFS) and intensity comes from added elements, not only level. Each file loops on its own with no gap: reverb tails and pad releases from the end are folded onto the start, and the high-pass filter is applied circularly. Use a player that loops by sample count (Vorbis decodes to the exact length measured below).

## How it was generated

```
python3 generate.py [outdir]   # renders all 13 files (about 15 s); deterministic (fixed seeds)
python3 verify.py [outdir]     # re-measures the .ogg files and writes measurements.md
```

Requires Python 3 with numpy and scipy, and ffmpeg with libvorbis. `generate.py` (in this folder) contains the whole recipe:

1. Percussion: TR-808 samples, 16th grid at 120 BPM with 10 % swing on odd 16ths, velocity variation, conga tumbao patterns, tom 3-3-3-3-4 pattern.
2. Synthesized: 909-style kick (pitch-swept sine tuned to A1, clicks, tanh), saturated groove bass (sub + decaying-filter saw), detuned-saw chord stabs and pads, glottal-saw formant "shouts" (vowel filters e/i/a/o/u), noise risers, crash.
3. Mix: sidechain ducking from the kick on bass/pads/stabs, synthetic stereo reverb sends, circular 28 Hz high-pass, loop tails folded onto the start.
4. Master: lookahead limiter on 4x oversampled peaks (ceiling -1.6 dBTP), gain iterated until the encoded `.ogg` itself measures the target LUFS (lossy coding shifts it up to about 1 dB on short files).

## Not verified

Nobody has listened to these files: all checks are numeric. Musical taste (groove, shout timbre, SFX character) needs a human listen; the shouts are synthetic and may sound robotic. Tweak the patterns in `round_layer()` and the levels in `main()` and re-run.
